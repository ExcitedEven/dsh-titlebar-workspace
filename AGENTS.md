# AGENTS.md

Desktop titlebar workspace chip for DeepSeek Harness. The profile links this
directory as `dsh-titlebar-workspace`; edits hot-reload into the running app.

## Commands

- `npm install` — dev-only (`typescript`, `@types/react`, `react`, `react-dom`,
  `jsdom`); the plugin has no runtime dependencies.
- `npm run build` — `tsc` compiles `src/` to `lib/` (committed so a linked
  install works without a build).
- `npm test` — builds, then jsdom: placement, layout shift, dots, blank
  handling, click targets.
- `npm run preview` — builds, then writes `tools/titlebar-preview.html`.

## Layout

- `src/client.ts` — the whole feature (browser bundle source); `lib/client.js`
  is generated by `tsc`.
- `src/index.ts` — empty host entry; `lib/index.js` is generated.
- `cordis.patch.yml` — inserts the entry.
- Edit `src/`, never `lib/`: `lib/` is build output.
- `test/`, `tools/` — jsdom test and preview generator (not shipped).

## Release

- Version follows SemVer. Keep `CHANGELOG.md` current, then run
  `npm version patch|minor|major` (bumps `package.json`, commits and creates
  the `vX.Y.Z` tag) and publish.
- Compatibility lives in `engines.dsh` and `dsh.engines.dsh`; keep them in sync
  when the minimum DSH version changes.

## Pitfalls

- The dropdown and flyout must stay portaled to `document.body`: the
  `shell.overlay` slot is a `z-index: 20` stacking context, and the right sidebar
  reaches `z-index: 90`.
- Only a *visible* `[role="dialog"][aria-modal="true"]` counts as a modal. The
  app keeps a hidden one mounted; a naive query closes the menu on open.
- Blank sessions: only the current one is listed (as `新对话`); blanks never
  count toward a status or a click target.
- Titlebar metrics mirror the Desktop titlebar controls (28px button, 6px radius,
  14px label). `--dsh-windows-menu-start` flips 48↔84px with the sidebar.
